How an implied value is made

Every live peer in a category reveals a market-cap / TVL multiple. A pre-token protocol is valued at TVL × its category's median peer multiple, adjusted for its 7-day TVL growth, for how long it has operated with no token recorded, and for how many chains it runs on. Nothing is hardcoded by name: change a figure in the snapshot and the board moves. Values are this radar's own claim about what a launch would be worth if the record stayed as it is — not a prediction that a token will come.
